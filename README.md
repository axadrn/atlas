# atlas

Not the real name. The real name needs a domain first.

The open source home for perpetual travelers.

Goal, said out loud: become the biggest digital nomad platform in the world.

## What it is

- Open data for countries, cities, visas and tax regimes
- Maintained like code
- Open source and built in public

## The stack

- Go
- templ
- shadcn-templ
- htmx
- SQLite

One binary. One box. That is the whole infrastructure.

## The builder

Built by one guy:

- Developer since 2019
- Perpetual traveler for just as long
- My own target group
- Vibecoding most of this, on purpose and in the open

I know what I am doing, which is exactly why architecture and everything
security relevant gets reviewed manually, to the best of my knowledge and
conscience. Both things are true at the same time.
